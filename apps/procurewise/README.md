# ProcureWise

MVP web/PWA para análise de reajustes de fornecedores.

## Funcionalidades atuais
- Preço atual x preço proposto
- Volume anual
- Custos de matéria-prima, processo e terceiros
- Custo total
- Markup implícito do preço proposto
- Markup-alvo por item
- Preço-alvo de negociação
- Saving anual potencial
- Classificação simples de risco
- Resumo executivo
- Exportação CSV
- Persistência local no navegador
- Funcionamento offline após o primeiro carregamento

## Como testar
Abra `index.html` em um servidor web estático. Para PWA/service worker, use HTTPS ou localhost.

## Monetização sugerida
- Free: até 10 itens por análise
- Pro: R$ 59/mês por usuário
- Business: R$ 249/mês por equipe
- Enterprise: preço sob consulta, incluindo workflow, benchmarks, integrações e governança

## Roadmap para produto comercial
1. Login e multiempresa
2. Banco cloud e histórico por fornecedor
3. Importação XLSX/CSV
4. Índices econômicos e câmbio
5. Workflow de aprovação
6. Relatório PDF / Recommendation Form
7. Stripe ou Mercado Pago
8. Controle de plano e limites
9. Dashboard de savings e reajustes
10. IA para leitura de cartas de reajuste e identificação de argumentos de negociação

## Observação
O MVP não substitui validação fiscal, técnica, contratual, compliance ou due diligence do fornecedor.
